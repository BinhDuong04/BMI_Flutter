Mục tiêu đề tài
Xây dựng ứng dụng giúp người dùng:
Tính chỉ số BMI (Body Mass Index)
Đánh giá tình trạng cơ thể (gầy, bình thường, thừa cân, béo phì)
Theo dõi và cải thiện sức khỏe
🧠 Kiến thức sử dụng
Lập trình di động với Flutter
Ngôn ngữ Dart
Thiết kế UI/UX cơ bản
Quản lý trạng thái (Provider / setState)
Tính toán công thức
⚙️ Công nghệ sử dụng
Thành phần	Công nghệ
Frontend	Flutter
Ngôn ngữ	Dart
IDE	Visual Studio Code / Android Studio
State Management	Provider
Thiết kế UI	Material Design
Thư viện	image_picker, intl (nếu có)
Chức năng chính
Nhập chiều cao, cân nặng
Tính BMI
Hiển thị kết quả
Phân loại sức khỏe
Giao diện trực quan
🧪 Hướng dẫn cài đặt
1. Cài đặt môi trường
Cài đặt Flutter SDK
Cài đặt Android Studio hoặc Visual Studio Code
Cài đặt Android Emulator hoặc dùng điện thoại thật
👉 Kiểm tra cài đặt:

2. Clone project
git clone https://github.com/ten-repo/bmi_app.git
cd bmi_app
3. Cài thư viện
flutter pub get
4. Chạy ứng dụng
flutter run
