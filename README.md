📌 1. Giới thiệu đề tài

Xây dựng ứng dụng di động giúp người dùng tính toán và đánh giá chỉ số BMI (Body Mass Index) nhằm hỗ trợ theo dõi và cải thiện sức khỏe cá nhân.
